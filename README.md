# 📊 TCS Stock Analysis using Python

This project is a simple yet practical analysis of **Tata Consultancy Services (TCS) stock data** using Python.  
The idea behind this project is to take real-world financial data, clean it, and then extract meaningful insights through data analysis and visualization.  

I’ve used Python libraries like **Pandas** for data handling and **Matplotlib/Seaborn** for visualizations. The focus is on understanding stock behavior such as price trends, highs & lows, and overall movement across a 5-year period

## 🔍 What’s Inside
- Data cleaning and preparation (handling missing values, formatting dates)  
- Exploratory analysis of stock prices (opening, closing, high, low)  
- Time-series visualizations to spot trends  
- Insights on TCS stock performance over time
